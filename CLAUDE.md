# Кинополка (kinopolka)

Сайт-библиотека фильмов без трейлеров и рекламы: название, год, страна, длительность, режиссёр, актёры, короткое описание без спойлеров. Начат 2026-10-15.

## Стек
- React 19 + Vite 8 + TypeScript 7 + Tailwind 4. Без сервера и без API-ключей: все фильмы лежат в коде.
- `npm run dev` — локально на http://localhost:5173, `npm run build` — проверка типов + сборка в `dist/`.
- `base: './'` в `vite.config.ts`, чтобы сайт работал на GitHub Pages по подпапке.

## Дизайн
- Паша хочет молочно-бордовые цвета и много анимаций. Тема по умолчанию — «молочная», вторая — «бордовая ночь» (ключ `kp-theme-v2`).
- Шрифты: Playfair Display (заголовки, курсив для акцентов) + Manrope (текст). Цвета — CSS-переменные в `src/index.css`.
- Анимации: появление шапки (`.rise`), плавающий фон (`.aurora`), зерно плёнки, бобина, бегущая строка (`Marquee.tsx`), рулетка (`Roulette.tsx`), карточки по очереди. Всё отключается при `prefers-reduced-motion`.

## Где что
- `src/data/*.ts` — фильмы (~300): `nashe.ts` (Россия/СССР), `animation.ts` (мультфильмы и аниме), `world-drama.ts`, `world-genre.ts`. Тип `Film` в `src/data/types.ts`. Описания пишем своими словами, без спойлеров, не копируем с Кинопоиска.
- `src/lib/labels.ts` — настроения, жанры, десятилетия, сортировки.
- `src/App.tsx` — поиск, фильтры, вкладки «Хочу посмотреть / Просмотрено», случайный фильм, ссылка на фильм через `#id`.
- `src/components/WikiSearch.tsx` — если фильма нет в библиотеке, ищем в русской Википедии (API без ключа).
- Личные списки и оценки — только в `localStorage` браузера (ключи `kp-marks`, `kp-theme`, `kp-sort`).
